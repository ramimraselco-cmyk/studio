# Deedox Studio — Web Development, SaaS & AI Agency

Official production codebase for [deedoxstudio.com](https://deedoxstudio.com).

## 🚀 Live Production & Deployment
- **Hosting**: Vercel Global Edge Network
- **Domain**: [https://deedoxstudio.com](https://deedoxstudio.com)
- **CMS & Video Engine**: Cloudinary CDN + Supabase Real-Time Database

## 📁 Core Features & Architecture
- **Primary Service**: Custom Website Development & Technical SEO
- **Core SaaS**: Custom Hospital Management (HMS), Hotel ERP, POS, and Multi-Tenant SaaS
- **Mobile Apps**: iOS, Android & Cross-Platform (React Native / Flutter)
- **AI Automation**: 24/7 WhatsApp & Messenger Chatbot Automation Systems
- **Creative Media**: Cinematic AI Commercials, UGC Ads & Graphic Design

## 🛠️ Local Development
```bash
npm install
npm start
```
Server runs at `http://localhost:3005`.
Admin portal is located at `/deedoxahmed7070`.

## 🔍 SEO & Technical Assets
- `robots.txt` — Full crawler rules for Googlebot, Bingbot, GPTBot, PerplexityBot, ClaudeBot
- `sitemap.xml` — Complete canonical sitemap with Google Image search extensions
- `site.webmanifest` & `favicon.svg` — PWA & modern vector favicon suite
- `vercel.json` — Edge caching, security headers (HSTS, CSP), and 301 redirects
